# Buffalo Milkcare Compass

O trabalho é voltado à criação de búfalas para produção de leite. O documento aborda principalmente:

Manejo das búfalas.

Cuidados com os bezerros.

Alimentação dos animais.

Higiene durante a ordenha.

Prevenção de doenças, como a mastite.

Vacinação e cuidados sanitários.

Armazenamento, resfriamento e transporte do leite.

Descarte dos dejetos dos animais. e faça um fiveicon de um bufalo
